# Handoff — рекомендации OpenMusic

20 ноября 2026 · ветка `feature/music-matcher-recommendations`

## Что готово

- Search, быстрый поиск, Made to discover и Liked Songs запускают трек обычным resolver по `video_id`. Рекомендации загружаются параллельно. В Up next ручные добавления идут первыми, затем похожие треки в порядке Music Matcher. Запоздалый ответ от предыдущего запуска отбрасывается.
- On repeat, Artists to explore, Made for you и Made to discover используют один ответ по последнему лайку. Удаление этого лайка переключает подборки на следующий. У гостя и пользователя без лайков подборки пусты.
- Демообъекты удалены из каталога и плеера. При загрузке пропускаются старые демолайки и числовые ссылки на демотреки в плейлистах. Реальные лайки остаются в MariaDB, плейлисты остаются на устройстве с исходным порядком реальных треков.
- Backend запускает парсер в отдельном процессе, даёт ему 18 секунд, затем до 12 секунд на поиск подтверждённых совпадений. Выполненные сопоставления возвращаются при частичном сбое. Карточка релиза открывает подтверждённые треки из рекомендаций по идентификатору альбома YouTube Music.

## Запуск

Установите Python-зависимости через `pip install -r backend/requirements.txt` и перезапустите backend по инструкции в [README](README.md). На Ubuntu 26.04 с Playwright 1.56.0 используйте системный Chrome или Chromium из `PATH`. На проверенной машине backend автоматически выбрал `/usr/bin/google-chrome`. На платформе, для которой Playwright поставляет Chromium, можно установить его командой `python -m playwright install chromium`. Миграция БД для рекомендаций не требуется.

## Проверки

- `npm run check`, `npm test`, `git diff --check`.
- Backend pytest — 21 тест прошёл. 15 тестов требуют отдельную тестовую MariaDB и были пропущены.
- В Chromium прошли `recommendations-ui.mjs`, `account-ui.mjs`, `artists-ui.mjs` и `fullscreen-ui.mjs` с контролируемыми ответами API. Сценарий рекомендаций проверяет запуск из Search и Liked Songs, A → B, приоритет ручного трека, автоматический переход, четыре подборки, снятие лайков, выход и открытие старого плейлиста.
- Живой API для Radiohead — No Surprises вернул 12 подтверждённых треков с метаданными релизов. Отдельный запуск парсера из рабочей `.venv` прошёл с автоматическим выбором Chrome.
- Реальный Telegram-вход и слышимость аудио в этой приёмке не проверялись.

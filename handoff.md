# YouTube Music Radio в OpenMusic

При ручном запуске трека интерфейс одновременно запрашивает аудио и радио по `video_id`. Кнопка Play в Liked Songs использует первый трек списка. В Up next сначала идут ручные добавления, затем оставшиеся треки выбранного списка, затем радио. Новый запуск заменяет выдачу радио. [ТЗ](docs/youtube-music-radio-spec.md)

Backend получает до 12 рекомендаций через `ytmusicapi`. Для локального запуска установите зависимости через `pip install -r backend/requirements.txt` и перезапустите backend. Playwright используется в браузерных тестах. [README](README.md)

Браузерный сценарий `tests/recommendations-ui.mjs` проверяет смену трека при незавершённом запросе, приоритет ручной очереди, переходы, паузу, повтор, обновление лайков и работу плеера при сбое радио. `backend/test_recommendations.py` проверяет порядок, фильтрацию, лимит и обработку таймаута.

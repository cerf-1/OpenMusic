# OpenMusic

Интерактивный визуальный концепт музыкального приложения: тёплый светлый интерфейс, лаймовый акцент, атмосферные фотообложки, стеклянный мини-плеер и полноэкранное прослушивание.

## Запуск

Из этой папки:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте `http://localhost:4173` через локальный сервер. Сборка и установка зависимостей не нужны.

## Что работает

- Подборки и альбомы, переключение разделов и настроений.
- Воспроизведение, пауза, перемотка, следующий и предыдущий трек.
- Громкость, перемешивание, повтор трека, редактирование очереди.
- Поиск по названию, исполнителю, альбому, жанру и подборке.
- Любимые треки и собственные плейлисты с сохранением в localStorage.
- Адаптивные интерфейсы для телефона, планшета и широкого экрана.
- Горячие клавиши: Ctrl/⌘ K — поиск; пробел — воспроизведение; Alt + стрелки — переключение треков; Escape — закрытие окна.

Это демонстрационный интерфейс. Названия треков и исполнители вымышлены. Шесть оригинальных музыкальных аранжировок воспроизводятся через Web Audio API, без внешнего каталога или аудиосервиса. Звук начинается только после нажатия пользователя. Данные коллекции хранятся на текущем устройстве.

## Файлы

- `dist/index.html` — структура приложения.
- `dist/style.css` — оформление, адаптивность и анимации.
- `dist/app.js` — экраны и пользовательские действия.
- `dist/audio.js` — оригинальные синтезированные демокомпозиции.
- [Источники фотообложек](asset-sources.md).
- [Промпт главной обложки](artwork-prompt.md), созданной встроенным image_gen; итоговый файл — `dist/assets/hero.png`.

Проверены синтаксис JavaScript, жизненный цикл аудиодвижка, последовательность очереди и основные сценарии в браузере: воспроизведение, перемотка, поиск, лайки, создание подборки, редактирование очереди, полноэкранный и мобильный режимы.
